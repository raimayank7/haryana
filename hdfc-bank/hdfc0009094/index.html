How the code HDFC0009094 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 009094 is the part that names this branch.

The MICR code 110240489 is the number printed along the bottom of this branch's cheques. 110 is the city, 240 is the bank and 489 is the branch.
