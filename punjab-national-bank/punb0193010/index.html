How the code PUNB0193010 is built

PUNB is the bank part: the letters of Punjab National Bank. The fifth character is always the digit 0. 193010 is the part that names this branch.

The MICR code 132024024 is the number printed along the bottom of this branch's cheques. 132 is the city (the same three digits that begin the PIN code 132113), 024 is the bank and 024 is the branch.
